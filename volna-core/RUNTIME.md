# SmartConnect async runtime

Второй инкремент добавляет настоящий async executor на Tokio/FuturesUnordered:
staggered launch, timeout каждой попытки, общий deadline, ограничение до 32
кандидатов и выбор достаточно хорошей сессии. При исчерпании попыток или deadline
можно вернуть лучшую уже проверенную сессию ниже порога.

Connector — контракт для реальных сетевых адаптеров. Он возвращает Ok только после
аутентификации и end-to-end проверки. Конкретных VPN-протоколов в этом инкременте
ещё нет. Синхронный TransportAdapter из первого инкремента не используется executor.

Сессии и частично установленные подключения обязаны освобождать ресурсы через Drop.
Executor не запускает detached tasks; отмена futures закрывает работу проигравших.
Async cleanup, если он нужен адаптеру, потребует отдельного контролируемого supervisor
до интеграции этого адаптера. Drop-контракт сам по себе не заменяет такую интеграцию.

watch generation меняется владельцем при Stop или смене сети. Executor отклоняет
устаревшие результаты и закрытие sender. Перед установкой маршрута платформа должна
повторно проверить generation: изменение сети возможно после возврата winner.
Возвращённая сессия ещё не активирована и не имеет права самостоятельно менять TUN.

Проверки используют виртуальное время: выигрыш гонки, зависшая попытка, закрытие
готового проигравшего, deadline, отказ аутентификации и отмена поколения.

Следующий шаг: конкретный адаптер с настройками endpoint/credentials и сетевой
стенд, проверяющий передачу IP и teardown при отмене. Затем signed config и Android.
