# ВМедА · Анатомия

Учебное веб-приложение (SPA) для подготовки студентов Военно-медицинской
академии к коллоквиумам и экзаменам по нормальной анатомии человека.

## Источники и подход к контенту

- **Теория** изложена по классической схеме И.В. Гайворонского («Нормальная
  анатомия человека»): *Определение → Классификация → Строение →
  Кровоснабжение и иннервация*.
- **Номенклатура** — латинские термины даны курсивом и соответствуют
  актуальной Международной анатомической номенклатуре (Terminologia
  Anatomica).
- **Иллюстрации.** Атлас Ф. Неттера и схемы И.В. Гайворонского защищены
  авторским правом, поэтому сами картинки в код не включены. Вместо них в
  разделе «Атлас» показан стилизованный плейсхолдер с точным указанием, какую
  иллюстрацию вставить (тема + источник). Приложение уже умеет подставлять
  реальный файл вместо плейсхолдера автоматически — см. раздел
  «Как добавить свои изображения» ниже.
- **Силуэт академии.** В шапке приложения — оригинальный стилизованный
  SVG-силуэт неоклассического здания академии (колонны, фронтон, купольная
  часть отсутствует — упрощённый портик), нарисованный с нуля для этого
  проекта. Это не фотография конкретного здания, а собирательный образ в духе
  Военно-медицинской академии.

## Как добавить свои изображения

Положите файл в `img/atlas/` с именем `<id темы>-<номер иллюстрации>.<jpg|jpeg|png|webp>`
— как только файл появится по этому пути, плейсхолдер в «Атласе» и в модальном
окне автоматически заменится на картинку (проверяются по очереди расширения
jpg → jpeg → png → webp, ничего в коде менять не нужно). Полный список всех
100 ожидаемых имён файлов — ниже, сгруппирован по разделам курса.


## Разделы теории

Остеология · Артросиндесмология · Миология · Спланхнология · Ангиология ·
Неврология · Органы чувств и покровы — всего 44 темы, каждая раскрыта по
схеме Гайворонского.

## Тренажёр латыни

Интерактивные флеш-карточки (флип по клику: русский ⇄ латынь) с фильтром по
разделам, перелистыванием вперёд/назад и перемешиванием колоды. Банк
включает около 100 терминов.

## Запуск

Приложение не требует сборки и бэкенда — статические HTML/CSS/JS.

```bash
cd vmeda-anatomy-app
python3 -m http.server 8080
# откройте http://localhost:8080 в браузере (мобильный вид — через DevTools)
```

Либо откройте `index.html` напрямую в браузере.
