# ВМедА · Анатомия

Учебное веб-приложение (SPA) для подготовки студентов Военно-медицинской
академии к коллоквиумам и экзаменам по нормальной анатомии человека.

## Источники и подход к контенту

- **Теория** изложена по классической схеме И.В. Гайворонского («Нормальная
  анатомия человека»): *Определение → Классификация → Строение →
  Кровоснабжение и иннервация*.
- **Номенклатура** — латинские термины даны курсивом и соответствуют
  актуальной Международной анатомической номенклатуре (Terminologia
  Anatomica).
- **Иллюстрации.** Атлас Ф. Неттера и схемы И.В. Гайворонского защищены
  авторским правом и не включены в код. Вместо изображений в разделе «Атлас»
  и в карточках тем используются стилизованные плейсхолдеры с точным
  указанием, какую иллюстрацию нужно вставить (тема + источник). Чтобы
  наполнить приложение реальными изображениями, замените блоки
  `.image-placeholder` в `js/data.js` (поле `atlas`) на теги `<img>` со
  своими файлами и подключите изображения в `js/app.js` (функции
  `renderAtlas` и `openPlateModal`).

## Структура проекта

```
vmeda-anatomy-app/
├── index.html        # разметка приложения, три экрана-вкладки
├── css/style.css      # iOS-стиль (glassmorphism, Tab Bar, San Francisco)
├── js/data.js         # содержание раздела «Теория» (7 разделов, 44 темы)
├── js/flashcards.js   # банк терминов для тренажёра латыни
├── js/app.js          # SPA-логика: вкладки, рендер, тренажёр
└── README.md
```

## Разделы теории

Остеология · Артросиндесмология · Миология · Спланхнология · Ангиология ·
Неврология · Органы чувств и покровы — всего 44 темы, каждая раскрыта по
схеме Гайворонского.

## Тренажёр латыни

Интерактивные флеш-карточки (флип по клику: русский ⇄ латынь) с фильтром по
разделам, перелистыванием вперёд/назад и перемешиванием колоды. Банк
включает около 100 терминов.

## Запуск

Приложение не требует сборки и бэкенда — статические HTML/CSS/JS.

```bash
cd vmeda-anatomy-app
python3 -m http.server 8080
# откройте http://localhost:8080 в браузере (мобильный вид — через DevTools)
```

Либо откройте `index.html` напрямую в браузере.
