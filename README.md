# VICEGRAM Bot — работа с PDF

Telegram-бот на [aiogram](https://docs.aiogram.dev/). Принимает PDF-файл и
предлагает два действия:

- 🗜 **сжать без потери качества**;
- ✂️ **выбрать страницы** — собрать новый файл только из указанных страниц
  (например, `1-135` или `1,3,5-10`).

## Как это работает

Обе функции построены на [pikepdf](https://pikepdf.readthedocs.io/)
(обёртка над `qpdf`) и не рендерят страницы заново — контент копируется
как есть, поэтому качество не теряется.

### Сжатие

- пересжимает внутренние потоки данных PDF (deflate/zlib с максимальным уровнем);
- убирает неиспользуемые и дублирующиеся объекты;
- упаковывает объекты в object streams.

Изображения при этом не пережимаются — итоговый файл выглядит идентично
исходному. Реальная экономия зависит от того, насколько PDF уже
оптимизирован: свежесгенерированные из LaTeX/Word/Google Docs файлы иногда
почти не сжимаются, а старые/несжатые файлы могут уменьшиться на 20–40%.
Если после сжатия размер не уменьшился, бот сообщает об этом и не
присылает файл повторно.

### Выбор страниц

Бот спрашивает номера страниц, парсит диапазоны вида `1-135` или список
`1,3,5-10`, копирует выбранные страницы в новый PDF (без дублей, в
порядке возрастания номеров) и присылает результат.

## Сценарий использования

1. Отправляете боту PDF-файл.
2. Бот показывает две кнопки: «Сжать» и «Выбрать страницы».
3. Если выбрали «Выбрать страницы» — присылаете номера, например `1-135`.
4. Получаете готовый файл. Команда `/cancel` отменяет текущее действие.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Впишите в `.env` токен бота, полученный у [@BotFather](https://t.me/BotFather):

```
BOT_TOKEN=123456:ABC-DEF...
MAX_FILE_SIZE_MB=20
```

## Запуск

```bash
python -m bot.main
```

## Ограничения

- Максимальный размер файла по умолчанию — 20 МБ (лимит стандартного
  Telegram Bot API на скачивание файлов ботом). Чтобы работать с большими
  файлами, нужен собственный [Local Bot API Server](https://github.com/tdlib/telegram-bot-api).
- PDF, защищённые паролем, бот обрабатывать не умеет.
- Состояние диалога (FSM) хранится в памяти процесса (`MemoryStorage`) —
  при перезапуске бота незавершённые сессии выбора страниц сбрасываются.

## Структура проекта

```
bot/
  main.py                   — точка входа, запуск polling
  config.py                 — чтение переменных окружения
  handlers/
    start.py                — /start, /help
    pdf_actions.py          — приём PDF, выбор действия, FSM выбора страниц
  services/
    pdf_errors.py            — общие исключения
    pdf_compressor.py        — логика lossless-сжатия (pikepdf)
    pdf_splitter.py          — парсинг диапазонов и извлечение страниц
requirements.txt
.env.example
```
