# MED VPN: универсальная маршрутизация

В Happ: .ru/.su/.рф и явный список российских сервисов напрямую, остальные назначения через VPN. Меню «Режим маршрутизации» или /routing выдаёт строку импорта, TXT и QR только при оплаченной действующей подписке. Credentials в профиле отсутствуют, личный сервер добавляется отдельно.

После импорта включите маршрутизацию, проверьте активный MED VPN Routing, переподключитесь. «Всё через VPN» заменяет профиль с тем же именем без публичных прямых исключений. Локальная сеть доступна в обоих режимах. Бот не может подтвердить применение на устройстве.

Схема https://github.com/Flyfrog-LLC/Happ-docs/blob/main/dev-docs/routing.md
GlobalProxy=true; без geoip:ru и исключений целых общих CDN. Неизвестные назначения через VPN. Список доменов: bot/routing_profiles.py; правила не требуют geodata. Прямые сервисы видят обычный IP, DNS напрямую к Яндекс 77.88.8.8 по UDP. Остальные DNS используют Cloudflare DoH. Ограничения провайдера/геоблокировки действуют на прямом пути. Сервис на другом домене может потребовать дополнения списка.

## Приёмка
Android, iOS/Happ Lite, Windows, macOS: импорт обоих профилей, проверка активности, банк/Госуслуги/Яндекс одновременно с YouTube/ChatGPT. Проверить IP на контролируемых прямом и проксируемом доменах, A/AAAA, DNS, Wi-Fi и мобильную сеть. Full должен удалить публичные прямые исключения. Проверить старые кнопки при истёкшей подписке.
CI проверяет импорт, QR, оплату и владельца при выдаче. Реальная маршрутизация требует проверки в Happ на устройствах.
Выкладка VPS: git pull --ff-only, sudo systemctl restart med-vpn-bot.
